# Музыка и плееры GremlinAmp

Музыкальная библиотека объединяет саундтреки игр и серий. Игровой файл может содержать несколько композиций: каждая отображается отдельной строкой, а её номер внутри исходника сохраняется как `subsong`. Это не обязательно отдельный MP3 для каждого трека.

## Где слушать

Веб-плеер работает в медиатеке и в подробных карточках с готовой музыкой. GremlinAmp для Android добавляет скачивание и офлайн-прослушивание, системное управление звуком и обновление сохранённых коллекций. Mac-версия музыкального приложения — отдельное направление разработки; её готовность нельзя выводить из готовности веб- или Android-плеера.

Оригинальные форматы NSF, NSFE, GBS, HES, SPC, VGM/VGZ, AY и SAP используют эмуляцию звуковых систем. MP3 и другие предоставленные записи используют обычное воспроизведение. Поддержка расширения файла не означает поддержку любого чипа внутри него. Реализация YM2413 согласована с GremlinAmp 0.2.4 через emu2413; ограничения конкретных форматов должны проверяться на реальном декодере.

## Управление веб-плеером

| Настройка | Правило |
| --- | --- |
| По списку | Следующая строка очереди; в конце — остановка |
| По ритму / По звучанию | Подбор по готовым акустическим признакам |
| После игры | Оставшиеся треки текущей игры, затем другая игра |
| После трека | Подбор после каждой композиции |
| Назад / Вперёд | История прослушивания; после её конца — выбранное продолжение |

Поиск следующего похожего трека идёт по всей медиатеке, что указано возле настроек. Новый ручной выбор начинает свою очередь. Смена режима сохраняет текущую композицию и уже начатую загрузку. При отсутствии пригодного индекса продолжается обычная очередь; если она закончилась, звук останавливается.

Акустический подбор не равен похожести игр по жанру, платформе или серии. Android-приложение может предлагать и такие режимы; их область и приоритет повтора определяет интерфейс конкретной версии.

## Скачивание

Один исходник может обслуживать несколько треков; загрузчик учитывает общие байты. Скачанные файлы проверяются по опубликованным размерам и SHA-256. Сетевые ограничения и автоматическое обновление в приложении управляются явно. Права на музыкальные произведения остаются у их правообладателей.
