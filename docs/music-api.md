# Музыкальный API и идентичность треков

Сайт предоставляет JSON-метаданные отдельно от исходных музыкальных файлов. Клиент читает каталог, открывает манифест нужного набора, выбирает строку и загружает её `asset`. JSON сам по себе не содержит звук.

## Публичные ресурсы

| Ресурс | Адрес от корня сайта |
| --- | --- |
| Наборы музыки | `music/index.json` |
| Медиатека игр и треков | `assets/gallery-music.json` |
| Манифест набора | Значение `manifest` из опубликованного каталога |
| Похожие треки | `assets/music-similarity.json` |
| Метаданные GremlinAmp | `assets/arcade/music-app/release.json` |

Значение `schema_version: 1` относится к структуре соответствующего музыкального JSON, а не к версии приложения или анализатора. Адрес манифеста берётся из данных. Относительный `asset.url` разрешается относительно манифеста; адрес набора из общей медиатеки — относительно корня сайта.

## Трек и оригинал

`game_id` связывает строку с набором игры; `index` указывает позицию в его треклисте. `id` сохраняет идентичность строки. `subsong` выбирает композицию внутри исходника. `asset.sha256` и `asset.bytes` описывают загружаемые байты.

Физический ключ звука — `SHA256:subsong`. Одинаковые байты и номер композиции не анализируются заново только из-за второй ссылки на них. Необязательное `audio_key` в индексе медиатеки передаёт этот ключ без предварительного скачивания полного манифеста.

Если манифест обновился, прежний индекс строки может указывать уже на другой материал. Перед подбором клиент проверяет набор, идентификатор строки и физический ключ. Несовпавший кандидат пропускается; угадывать композицию по одному названию нельзя.

## Длительность

`duration_known` различает известную длительность и условную границу воспроизведения. `play_ms` и `fade_ms` задают соответствующие времена в миллисекундах. Неизвестная длительность не равна нулевой и не доказывает, что файл короткий.

Схемы и синтетические примеры находятся в [реестре форматов](formats.md). Наличие индекса сходства необязательно для обычного воспроизведения.

## Поля индекса сходства

`tracks` — словарь по физическому ключу. В записи: `refs` со связями `{game_id, track_id, index}`, оценка `bpm`, `rhythm_confidence`, `partial` и `neighbors`. Последний содержит списки `rhythm` и `sound`; кандидат имеет `key` и `distance`. Пустой список допустим. Версия анализатора и engine описывают метод; fingerprint — содержимое индекса. Distance не является вероятностью или процентом.

## Метаданные приложения

Метаданные приложения `release.json` имеют title, description, icon_url, version, build, apk `{url, bytes, sha256}`, source_url, min_android. Поле schema_version для этого файла не требуется. Ссылка на исходники берётся из source_url, а не из имени APK.
