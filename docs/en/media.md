# Media library, viewing and search

The media library connects illustrations, game and series posters, music, views and wallpapers. These are distinct kinds of material: changing a picture does not select a track, and a weather change does not require choosing another catalogue game.

The gallery provides previews, available variants and links to related material. Full viewing reveals picture details and the offered download. Previews can be smaller than originals; a small page block need not load the largest picture immediately.

A dynamic collection selects a device and shows its current frame. A weather collection selects artwork, weather source and format independently. A ready-made dynamic frame does not require manual weather-state selection.

Search narrows visible material. Direct links identify a material or section. Availability follows published metadata, not guessed file addresses. In the music library, search and the game selector affect a new manual selection without rebuilding an already playing queue. Acoustic continuation explicitly states its search scope.

Applications can save collections for offline use according to their version. An offline collection does not establish the freshness of today's forecast. See [formats and integration](formats.md) and [music players](music.md).
