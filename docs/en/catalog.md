# Game catalogue and data sources

A game card combines reference information, personal experience and available materials: posters, guides, music and series relationships. Main sections represent played games, recommendations, future plans and games of the week. A reference game in a series does not imply that the author has played it.

## Types of information

| Information | Basis |
| --- | --- |
| Achievements and completion | RetroAchievements data and the player profile |
| Competitive results | The relevant leaderboards and cited sources |
| Release, platform, developer, series | Game reference sources and confirmed relationships |
| Completion time | The named source, not a guaranteed duration for a future session |
| Impressions and recognition | The author's writing and game journal |
| Illustration | A separate artistic work |

Sources include RetroAchievements, Speedrun.com, MARP, IGDB, MobyGames, HowLongToBeat, LaunchBox and Libretro. A supported source does not mean every card contains every field. Missing information is not replaced with a zero result or an invented fact.

## Game identity

A game, a release and a platform are related but distinct. A title alone does not establish identity. Stable source identifiers support external relationships when available. Series membership connects reference games without turning reference information into the author's personal experience.

Filters and search select materials; detailed cards reveal the data and links. Site artwork can change while the game's identity and source references retain their purpose. See [journal and recognition](journal.md), [music](music.md) and [sources and rights](sources.md).
