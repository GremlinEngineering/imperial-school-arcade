# Site and game visual identity

Calendar themes change the site's artistic appearance for seasons and events. They are separate from desktop weather wallpapers: a page theme does not change the selected weather source or replace a device's wallpaper theme.

A theme connects colours, controls, logos, illustrations, and light and dark variants. Consistent characters, scale and placement turn the pictures into a visual system. A game poster, an alternative poster composition, a section illustration and a link preview have different purposes. Link images must remain readable at a small size.

Day and night are variants of the same identity. Seasonal and event themes can change accents while preserving a card's meaning. A full-size picture, a small preview and a social-link image may use different resolutions without representing different games or events.

An unfinished theme must not be presented as a finished collection. Output dimensions do not guarantee the same original drawing detail. An artistic reference to a game or period does not imply endorsement by its rights holder. See [media](media.md), [wallpapers](wallpapers.md) and [Teahouse composition](composition.md).
