# Спецификация погодного API

Публичный контракт Weather 1.7 сохраняет модели источников, интервалов и форматов из семейства API 1.x. Версия документа и значение `schema` — разные величины. Базовый адрес: `https://games.oopssre.ru/assets/arcade/views/`.

Все относительные пути из погодных JSON разрешаются от этого базового адреса, включая пути внутри вложенного прогноза. Их нельзя разрешать от папки самого `forecast-*.json`.

## Ресурсы и схемы

| Ресурс | Путь от базового адреса | Схема |
| --- | --- | --- |
| Каталог | `manifest-v3.json` | `schema: 3` |
| Реальное текущее состояние | `weather/C/current.json` | `schema: 1` |
| Реальный прогноз формата | `weather/C/forecast-D.json` | `schema: 1` |
| Текущее состояние мира | `weather/C/sources/game-world/current.json` | `schema: 1` |
| Прогноз мира | `weather/C/sources/game-world/forecast-D.json` | `schema: 1` |
| Подготовленные изображения | `weather/C/assets.json` | `schema: 1` |
| Прямой текущий JPEG | `weather/C/current-D.jpg` | Изображение |
| Прямой JPEG мира | `weather/C/sources/game-world/current-D.jpg` | Изображение |

`C` — ID коллекции, `D` — объявленный ключ формата. Адреса прямых JPEG используются только при их наличии в опубликованных данных. Поддержка формата и готовность конкретного изображения проверяются отдельно.

## Источник и интервалы

Коллекция определяет рисунки, `source_id` — источник погоды. Публичные источники семейства API: `real` и `game-world`. Реальному источнику не требуется дополнительная папка `/sources/real/`. `world_id` относится к игровому окружению, `location_revision` — к ревизии местоположения и его параметров.

Для подписи окружения используется `source.setting` с запасным вариантом `source.name`. Текущие сезон, свет и `world_date` берутся из интервала. Время интервала задаёт срок применения кадра; таймер клиента должен переключать изображение по границам, а не только раз в сутки.

## Обновления и отсутствие данных

Один постоянный URL может отдавать новые байты. Различать их нужно по опубликованным версии и SHA-256. Если прежний JSON ожидает старую сумму, а сервер уже отдаёт другой файл, следует обновить каталог и прогноз. Несовпавший файл не считается проверенным кадром.

При недоступности используются явные статусы API. Ещё действующий совместимый прогноз можно продолжить при сетевом сбое; просроченный нельзя произвольно продлевать. Общая иллюстрация `weather_fallback` — отдельный материал недоступности, а не новое погодное состояние или JPEG нужного размера.

## Небесные признаки

Время суток и события Солнца зависят от даты, координат и явного часового пояса. Фаза Луны — одно из восьми объявленных значений. Если расписание содержит более точные границы, клиент следует ему. Локальные дата и часы устройства не должны подменять календарь игрового мира.
