# Форматы на границах системы

Каждый этап получает подготовленные данные и возвращает результат определённой формы. Ниже разобраны идентичность игры, вход текстовой задачи, контекст серии и данные оформления. 

## Игра и версия

Минимально полезная запись содержит внутренний идентификатор карточки, идентификаторы внешних источников, платформу, название, доступную точность даты и роль карточки: личная, план, рекомендация или справочная.

Внешний ID и платформа используются по правилам конкретного источника. ID произведения не доказывает тождество всех его портов. Подтверждённые связи с сериями хранятся отдельно от сходства названий.

Факт и его происхождение полезно держать вместе: значение, источник, точность и дата наблюдения. Эта запись позволяет проверить, откуда взялось значение и насколько оно точно.

## Точный вход синтеза взглядов

Задача синтеза двух взглядов получает следующие поля:

```json
{
  "title": "Демонстрационная игра",
  "year": 1991,
  "platform": "NES",
  "weekly_view": "Первое знакомство: точные прыжки и короткие уровни.",
  "played_view": "После прохождения заметнее система маршрутов."
}
```

Ответ содержит непустую строку `view`. Валидатор этого этапа отклоняет заголовки, URL и служебные маркеры цитирования. Перед запуском подтверждается пара карточек: RA ID и платформа совпадают. Для расчёта основания используются также ключ недельного выпуска и точные исходные тексты.

Файлы [входа](../examples/view-input.json) и [ответа](../examples/view-output.example.json) — синтетический пример формата. Значения в этих файлах демонстрационные.

## Контекст обзора серии

Существующая задача получает объект `series` и массив `saved_game_texts`. В `series` передаются идентичность и название серии, источник, известные участники и пометка о возможной неполноте состава. Для готовых текстов игр используются поля `ra_id`, `title`, `platform`, `view`, `place_in_history`, `series_context`.

Так обзор может работать с уже исследованными материалами. Повторная обработка должна сохранять различие между внешним фактом, сгенерированным текстом и авторской заметкой.

## Снимок состава серии

Точный формат примера функций:

```json
{
  "schema": 1,
  "series": [
    {
      "id": "demo-series",
      "members": [["ra", 101, true], ["ra", 202, false]]
    }
  ]
}
```

Числа здесь — синтетические идентификаторы. Третье значение — признак личного участника. Снимок канонизируется и сравнивается по составу; причина изменения вычисляется по самим участникам.

## Темы и лаборатория

Пакет темы объединяет оформление, запись собственного календаря, политику показа и данные подборки. Реестр иллюстраций хранит состояния и контрольные суммы оригиналов. Максимум подборки — десять игр. Лабораторная игра задаётся отдельной связью `laboratory_id`, а не фиктивным RA ID.

Если обязательный ресурс темы отсутствует, она целиком исключается из выбора. Выбирается доступное резервное оформление. Проверка целостности выполняется до выбора оформления для публикации.

Игра лаборатории содержит сведения об оригинале, реконструкции, источниках, управлении, приложении и постере. Исторический оригинал описывается отдельно от браузерной реконструкции, в том числе в структурированных метаданных.
