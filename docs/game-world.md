# Погода игрового мира

Погодное оформление и источник погоды независимы. Рисунки одной коллекции могут показывать погоду другого игрового окружения. Название активного мира, его календарь и источник нужно брать из опубликованных данных, а не угадывать по картинке.

## Источники

«Погода Столицы Империи» — серверный реальный источник. «Игровой мир» — подготовленное окружение активной игры с собственным климатом и календарём. Погода города, который пользователь выбрал в Open-Meteo, — третий сценарий на поддерживающем его клиенте. Название самостоятельно выбранного города не является подписью серверной погоды.

## Календарь

Игровой год и начальный сезон принадлежат миру игры. Они не обязаны совпадать с реальным годом и текущим месяцем. После выбранного начала календарь идёт по одному игровому дню за реальный день. Текущая дата передаётся как `world_date`; начальный сезон не следует использовать вместо текущего сезона интервала.

Погода мира задаётся климатической моделью; время рассвета, заката и лунные признаки рассчитываются для соответствующей даты и окружения. Клиент читает подготовленные результаты. Открытие картинки не требует нового создания мира.

## Изменение окружения

`world_id` идентифицирует мир. `location_revision` позволяет отличить изменение местоположения или его параметров, даже когда мир сохранил идентификатор. При смене ревизии прежнее расписание нельзя считать автоматически пригодным.

Если новый мир ещё не подготовлен, доступность должна следовать статусу API. Совместимый прогноз можно использовать в пределах его срока действия. Просроченный прогноз не превращается в новый только потому, что картинка осталась в кеше.

Полные поля и правила разрешения URL — в [погодном API](weather-api.md).
