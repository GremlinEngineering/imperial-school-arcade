# Пакеты оформления сайта

Пакет оформления сайта, коллекция обоев и динамическая тема устройства имеют разные контракты. Пакет сайта управляет календарём оформления, палитрой, ресурсами и иллюстрациями страниц. Он не переименовывает устройства коллекций.

## Контракт r11

Папка пакета содержит `theme.json` и `manifest.json`. В `theme.json`: `schema: 1`, `id`, непустой `title`, `kind`. ID совпадает с именем папки и содержит безопасный идентификатор. `kind`: `default`, `season`, `manual`, `holiday`, `birthday`, `game`, `console`, `company`.

| Поле | Назначение |
| --- | --- |
| `palette` | Палитра оформления |
| `styles`, `scripts` | Списки относительных ресурсов пакета |
| `files` | Соответствие публичного `assets/...` локальному файлу |
| `calendar` | Календарная запись с тем же id; сезон задаёт start |
| `icons` | Публичные значки, объявленные в files |
| `artwork` | full по умолчанию или none |
| `media` | visibility: always, hidden, event-day; preview и current — boolean |

`manifest.json` имеет `schema: 1`, `images`. Полный режим требует утверждённые 22 сцены в вариантах day/night: 44 изображения. Ключ иллюстрации — `<theme>/<scene>/<period>`. В режиме none словарь images пуст; оформление предоставляет другие ресурсы. Путь файла не выходит за пакет, отсутствующий ресурс не заменяется рисунком из другой темы. Общий публичный путь двух пакетов допускает только одинаковые байты.

Описание относится к формату готового пакета и его подключению. Программные расширения пакетов не являются переносимым художественным форматом для произвольного клиента. Установка приложения и JSON его релиза также имеют собственный контракт.
