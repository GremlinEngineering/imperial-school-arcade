# Аркадный зал Школы Империи

[English](README.en.md) · [Открыть сайт](https://games.oopssre.ru/)

Автобиография Дмитрия Малыхина, собранная из данных об игровом опыте и рассказанная через ретроигры. **Когда я играю — сайт меняется.** Каталог, журнал, музыка, иллюстрации, приложения и исследования соединяются через общие игры и события.

## Как читать эту документацию

При первом знакомстве начните с [идеи проекта](docs/project.md), затем посмотрите [каталог](docs/catalog.md), [журнал](docs/journal.md) и [медиатеку](docs/media.md). Это объясняет, что получает читатель. Следующая часть показывает общее устройство системы. Далее идут отдельные подпроекты и художественные примеры. Точные спецификации и полные задания вынесены в справочную и практическую части.

Документация предназначена читателям сайта, авторам материалов и разработчикам интеграций. Для подключения приложения используйте документацию его репозитория; для JSON и правил темы — соответствующую спецификацию ниже.
