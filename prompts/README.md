# Промпты по задачам

Полные тексты сгруппированы по работе каталога. У каждого задания указаны вход, результат и следующий шаг.

## Игра недели

От фраз и постов недели к выбранной игре, редакционному тексту и готовому выпуску.

### 1. [Выбор игры](01-weekly/01-selection.md)

**Вход:** Фразы месяца и недели, посты с ID, допустимые платформы и исключённые игры.

**Результат:** JSON: проверенная версия game, editorial_bridge и объяснение связи с неделей.

**Далее:** Недельное описание.

### 2. [Недельный «Взгляд»](01-weekly/02-editorial.md)

**Вход:** Выбранная game с механиками, editorial_bridge, бюджет подписи; при правке - прежний текст и режим repair_text.

**Результат:** JSON с description, angle, mechanic_ids и scene_seed; режим правки также возвращает механики и обоснование выбора.

**Далее:** Постановка сцены; превышение лимита даёт отдельную попытку сокращения.

### 3. [Визуальный сценарий недели](01-weekly/03-visual.md)

**Вход:** Подтверждённая версия игры, редакционный текст, точные надписи, референс и признак участия Лисы.

**Результат:** Структурированный POSTER DESIGN: сцена, узнаваемые детали, персонажи и художественная постановка.

**Далее:** Генерация недельного плаката.

### 4. [Недельный плакат](01-weekly/04-poster.md)

**Вход:** Готовый POSTER DESIGN, сведения о версии, точные надписи и изображения-референсы.

**Результат:** Вертикальный игровой плакат PNG 1024×1536.

**Далее:** Проверка изображения.

### 5. [Проверка недельного плаката](01-weekly/05-review.md)

**Вход:** Кандидат изображения, постановка сцены, данные игры и референсы персонажей.

**Результат:** JSON с решением проверки и конкретными замечаниями к изображению.

**Далее:** Сохранение принятого выпуска либо повторная попытка в пределах лимита.

## Личная карточка

От подтверждённого игрового опыта к «Взгляду», игровым опорам и афише эпохи игры.

### 1. [Редакционный текст](02-played/01-editorial.md)

**Вход:** Сведения о версии игры, описания доступных и полученных достижений, режим задачи.

**Результат:** JSON с description и mechanics; в режиме mechanics_only — только mechanics.

**Далее:** Визуальный сценарий.

### 2. [Визуальный сценарий](02-played/02-visual.md)

**Вход:** Название, платформа, дата версии, готовый «Взгляд», игровые опоры и референсы персонажей.

**Результат:** JSON с постановкой сцены, персонажами, композицией, художественным направлением и visual_prompt.

**Далее:** Генерация плаката.

### 3. [Генерация плаката](02-played/03-poster.md)

**Вход:** Готовая постановка POSTER DESIGN, точные название и платформа, референсы персонажей.

**Результат:** Изображение игрового рекламного плаката.

**Далее:** Проверка плаката.

### 4. [Проверка плаката](02-played/04-review.md)

**Вход:** Сгенерированный плакат, постановка сцены, сведения об игре и референсы персонажей.

**Результат:** JSON: status, проверки checks и список конкретных замечаний issues.

**Далее:** Сохранение принятого изображения либо повторная попытка в пределах лимита.

## Карточка «На будущее»

Знакомство с игрой, которую хочется попробовать: редакционный текст, конкретные действия и комиксная афиша.

### 1. [Редакционный текст](03-planned/01-editorial.md)

**Вход:** Название, платформа, сведения об игре и доступных достижениях; режим задачи.

**Результат:** JSON с description и mechanics; для неподтверждённой версии — пустые поля по правилам промпта.

**Далее:** Визуальный сценарий.

### 2. [Что попробовать в запланированной игре](03-planned/02-discovery.md)

**Вход:** Игра и платформа, доступные достижения, сохранённые «Взгляд» и игровые опоры.

**Результат:** JSON с what_to_try: два-три конкретных действия для знакомства с игрой.

**Далее:** Сохранение блока в подробной карточке.

### 3. [Визуальный сценарий](03-planned/03-visual.md)

**Вход:** Название, платформа, готовый «Взгляд», игровые опоры и референсы персонажей.

**Результат:** JSON с описанием одного кадра, композицией и visual_prompt.

**Далее:** Генерация иллюстрации.

### 4. [Генерация иллюстрации](03-planned/04-poster.md)

**Вход:** Готовая постановка сцены, название игры, платформа и референсы персонажей.

**Результат:** Иллюстрация знакомства с миром игры.

**Далее:** Проверка иллюстрации.

### 5. [Проверка иллюстрации](03-planned/05-review.md)

**Вход:** Иллюстрация, игровая постановка и референсы персонажей.

**Результат:** JSON: status, checks и issues.

**Далее:** Сохранение принятого изображения либо повторная попытка в пределах лимита.

## Рекомендации

От сигналов интереса к выбору игры, обоснованию рекомендации и современной афише.

### 1. [Отбор игр](04-recommendations/01-selection.md)

**Вход:** top_games, допустимые candidates, справочник платформ consoles и requested_count.

**Результат:** JSON со списком recommendations: game_id, why_recommended и what_to_try.

**Далее:** Редакционный текст для выбранной игры.

### 2. [Редакционный текст](04-recommendations/02-editorial.md)

**Вход:** Сведения о выбранной версии игры и доступных достижениях; режим задачи.

**Результат:** JSON с description и mechanics.

**Далее:** Визуальный сценарий.

### 3. [Причина рекомендации, действия и девиз афиши](04-recommendations/03-discovery.md)

**Вход:** Версия игры, основание отбора, доступные достижения, сохранённые «Взгляд» и игровые опоры; отдельный режим tagline_only.

**Результат:** JSON с why_recommended, what_to_try и tagline; в режиме tagline_only - только авторский девиз.

**Далее:** Сохранение блоков карточки и передача девиза в афишу.

### 4. [Визуальный сценарий](04-recommendations/04-visual.md)

**Вход:** Название, платформа, готовый «Взгляд», игровые опоры и референс Гремлина.

**Результат:** JSON с постановкой современного игрового key art и visual_prompt.

**Далее:** Генерация афиши.

### 5. [Генерация афиши](04-recommendations/05-poster.md)

**Вход:** Готовая постановка сцены, название игры, платформа и референс персонажа.

**Результат:** Изображение современной игровой афиши.

**Далее:** Проверка афиши.

### 6. [Проверка афиши](04-recommendations/06-review.md)

**Вход:** Афиша, постановка сцены, сведения об игре и референс персонажа.

**Результат:** JSON: status, checks и issues.

**Далее:** Сохранение принятого изображения либо повторная попытка в пределах лимита.

## Связи между материалами

Два взгляда на одну версию, контекст серии, историческое место и признание игры.

### 1. [Совместный взгляд на игру](05-context/01-view-synthesis.md)

**Вход:** title, year, platform, weekly_view и played_view для подтверждённой версии игры.

**Результат:** JSON с непустой строкой view.

**Далее:** Сохранение совместного текста рядом с двумя исходными взглядами.

### 2. [Справочная карточка игры](05-context/02-reference-card.md)

**Вход:** Название, платформа и известные сведения об игре и её месте в серии.

**Результат:** JSON с коротким описанием view.

**Далее:** Добавление справочной карточки в контекст серии.

### 3. [Место игры в серии](05-context/03-game-in-series.md)

**Вход:** game, saved_view, saved_mechanics, saved_history, saved_series_texts, series, requested_series_ids и saved_contexts.

**Результат:** JSON с text и прямыми ссылками sources.

**Далее:** Сохранение раздела в личной карточке игры.

### 4. [История конкретной серии](05-context/04-series-view.md)

**Вход:** series и saved_game_texts: состав серии, платформы и подготовленные тексты игр.

**Результат:** JSON с text и прямыми ссылками sources.

**Далее:** Публикация вступительного «Взгляда» на странице серии.

### 5. [Место игры в истории](05-context/05-game-history.md)

**Вход:** Версия игры и уже изложенные тексты: «Взгляд», игровые опоры, контекст серий и сохранённая история.

**Результат:** JSON с text и sources: исторический контекст и прямые ссылки на использованные источники.

**Далее:** Проверка и сохранение исторического раздела личной карточки.

### 6. [За что её помнят](05-context/06-remembered.md)

**Вход:** Игра, признание в исторических списках и готовые тексты карточки.

**Результат:** JSON с text и source_url: самостоятельная колонка о свойствах и исторической заметности игры.

**Далее:** Сохранение материала для подходящей личной версии.

## Названия, переводы и подлинные фразы

Поиск принятого названия, подтверждение исторической фразы и перевод исходных условий без изменения фактов.

### 1. [Русское название игры](06-facts/01-game-title.md)

**Вход:** Оригинальное название конкретной игры, платформа и год при наличии.

**Результат:** JSON с title_ru и source_url либо null-полями при отсутствии подтверждения.

**Далее:** Сохранение принятого русского названия с результатом поиска.

### 2. [Русское название серии](06-facts/02-series-title.md)

**Вход:** title_original и known_games для распознавания серии.

**Результат:** JSON с title_ru и source_url либо null-полями при отсутствии подтверждения.

**Далее:** Сохранение русского названия серии.

### 3. [Подлинная фраза игры](06-facts/03-game-tagline.md)

**Вход:** Название версии, год и платформа; для translate_only - готовая phrase.

**Результат:** JSON с text, kind, source_url и translation_ru; при переводе - translation_ru; неподтверждённая фраза даёт null.

**Далее:** Сохранение исходной фразы и перевода в карточке.

### 4. [Подлинная фраза серии](06-facts/04-series-tagline.md)

**Вход:** Название серии и известные части.

**Результат:** JSON с text, kind, source_url и translation_ru либо null-полями при отсутствии подтверждённой фразы.

**Далее:** Сохранение девиза или цитаты серии.

### 5. [Перевод достижений](06-facts/05-achievements-translation.md)

**Вход:** game_id и achievements с ID, исходным названием и описанием.

**Результат:** JSON achievements: те же ID и порядок, title_ru и description_ru.

**Далее:** Сохранение перевода рядом с исходными условиями.

### 6. [Перевод таблиц рекордов](06-facts/06-leaderboards-translation.md)

**Вход:** leaderboards: ID, title, description, название игры, платформа и формат результата.

**Результат:** JSON leaderboards: те же ID и порядок, title_ru и description_ru.

**Далее:** Сохранение перевода без пересчёта результатов и мест.

## События и характеристика

Короткая подводка к подтверждённым изменениям и литературная обработка вычисленных черт.

### 1. [Подводка к событиям журнала](08-journal/01-event.md)

**Вход:** Тип события, event_ids и подтверждённые facts; числовые результаты и ссылки публикуются отдельным этапом.

**Результат:** JSON с text: один абзац до 450 знаков.

**Далее:** Сохранение подводки рядом с детерминированной сводкой фактов.

### 2. [Характеристика Гремлина](08-journal/02-character.md)

**Вход:** character: уже вычисленные подписи, формулировки, trait_ids и подтверждающие произведения.

**Результат:** JSON character с теми же подписями и порядком; до 280 знаков на строку.

**Далее:** Проверка неизменности оснований и сохранение литературной характеристики.
