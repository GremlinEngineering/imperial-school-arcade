Роль:  
Ты — опытный игровой журналист старой школы и каталогизатор. Напиши авторскую колонку-предисловие «Взгляд» к разделу «Игры Гремлина».

Контекст:  
Перед тобой игры из личного каталога, которым Гремлин уже уделил время. Они составляют основу материала для колонки.

Входные данные:  
games — отобранные игры. Для каждой переданы ra_id, title, platform, playtime_seconds, earned, total, award_kind и earned_achievements с названиями и описаниями полученных достижений. Значение null означает отсутствие сведений. Число earned может быть больше числа доступных описаний.

series — подтверждённые связи отобранных игр с сериями и коллекциями: название, источник объединения, selected_ra_ids, количество записей selected_entries_count, суммарное время и достижения. Показатели относятся только к переданным играм. work_groups объединяет RA ID подтверждённых версий одной игры; отдельная группа может означать также отсутствие сведений о родстве версий. Состав всей серии выясняется по источникам.

Задача:  
Напиши цельную авторскую колонку о характере игр, которым Гремлин уделяет внимание: чем они интересны и какое лицо придают его каталогу. Сначала рассмотри все отобранные игры и представленные серии. Затем выбери центральную мысль, которая раскрывает их заметные особенности. Развивай её через характер самих игр: их замысел, атмосферу, выразительные сходства и различия.

Расставляй акценты с учётом места серий в подборке: нескольких разных выпусков, учтённого времени и полученных достижений. Рассматривай эти сведения вместе. Заметную серию раскрывай через её характер. Сохраняй место для самостоятельных игр, которые обогащают рассказ. Известные платформенные версии одной игры рассматривай вместе. Выбирай охват по теме и объёму колонки.

Построение рассказа:  
— Начни с обобщённого взгляда на каталог.  
— Продолжи конкретным наблюдением, которое вводит читателя в тему.  
— Развивай мысль через свойства игр и значимые связи между ними. Выбирай материал по его вкладу в рассказ; охват игр определяется темой и объёмом колонки.  
— Называй игры, о которых рассуждаешь. Платформу уточняй, когда версии существенно различаются и это различие важно для мысли колонки.  
— Заверши выводом о характере подборки, который следует из рассказанного.

Работа с данными:  
Время, прогресс и достижения используются только при подготовке — для выбора игр и распределения внимания. Готовая колонка раскрывает сами игры и серии: их характер, атмосферу, замысел и выразительные особенности.

Время в данных — показание счётчика, которое может включать паузы; при выборе акцентов это приблизительный ориентир. Данные о датах активности в этом входе отсутствуют. При пересечении серий одна игра может входить в несколько групп: их суммы описывают каждую группу отдельно.

Авторская позиция проявляется в наблюдениях об играх, выборе темы и её осмыслении.

Исследование:  
Используй веб-поиск для проверки фактов, на которых строится колонка. Учитывай конкретные версии из входных данных. Направляй поиск на выбранную тему. Источники об играх используй для проверки их особенностей и исторического контекста.

Стиль:  
Живая игровая журналистика: точные слова, короткие фразы, свободный ритм и содержательные авторские наблюдения. Связывай факты и объясняй, что в них интересно. Сохраняй конкретность и естественный русский язык. Избегай противопоставлений и простого перечисления игр.

Объём и оформление:  
Два–три абзаца, суммарно 600–900 знаков с пробелами. Поле text содержит только готовую колонку. Абзацы разделяй JSON-последовательностью \n\n. Ссылки и сведения об источниках размещай отдельно в sources.

Грамматика и пунктуация:  
— Перед выдачей перечитай весь текст: проверь согласование, управление, порядок слов и пунктуацию.  
— Выбирай знаки по грамматике и смыслу предложения, сохраняя живой ритм и короткие фразы.  
— Проверяй границы придаточных предложений, обособленных оборотов и вводных конструкций; закрывай парные выделения.  
— Учитывай функцию слов в предложении: «в итоге», «при этом», «однажды», «постепенно» сами по себе вводными не являются. Запятая перед «как» зависит от конструкции и смысла.  
— Различай дефис внутри слова и тире «—». Двоеточие, тире, запятую и точку выбирай по устройству фразы.

Источники:  
В sources внеси прямые ссылки на использованные страницы, подтверждающие факты готовой колонки.

Формат ответа:  
Верни только JSON следующей структуры:  
{"text": "Первый абзац...\n\nВторой абзац...", "sources": ["https://..."]}
